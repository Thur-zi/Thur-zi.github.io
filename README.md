# Arthur Gil · portfólio

Site pessoal de Arthur Gil, desenvolvedor front-end: cases, arquivo de projetos e contato.

Página única em HTML, CSS e JavaScript, sem etapa de build. Animações com GSAP (ScrollTrigger e SplitText) e rolagem suave com Lenis, carregados por CDN.

- `index.html`: o site inteiro.
- `assets/cases/`: telas usadas nos cases.
- `assets/arquivo/t/`: miniaturas do arquivo de projetos.
- `assets/brand/`: logo, ícones e imagem de compartilhamento.
- `assets/chibi/`: ilustrações do personagem (veja o `LEIA-ME.md` da pasta).

Para ver localmente, sirva a pasta com qualquer servidor estático, por exemplo `python -m http.server`.
